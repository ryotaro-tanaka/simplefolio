Current Project: JobHuntX

Overview

JobHuntX is a job information aggregation application that collects job postings from multiple sources such as public APIs, RSS feeds, and websites, and enables efficient job search.

🔧 Tech Stack: ASP.NET Core, React, TypeScript, Docker

See Live Source Code

Why I built JobHuntX

After moving to Australia, I faced difficulty finding jobs suitable for skilled migration (subclass 190/491). Most job boards lacked filtering for PR pathways.

I decided to create my own tool that scrapes and aggregates job listings with customizable filters to assist in my search—and to showcase my abilities to employers.

Key Features

- To flexibly and extensibly handle multiple job sites and APIs, I designed concrete implementations (RSS, API, scraping) that inherit from an abstract job source handler.

- To improve the performance of external data retrieval and reduce API load, I introduced caching using IMemoryCache.

- To efficiently identify the cause of issues and streamline maintenance, I implemented centralized error handling and logging.

- To prevent data integration errors between backend and frontend and improve development efficiency, I designed a type-safe frontend API using NSwag.

- To ensure quality and enable safe future feature additions and refactoring, I support CI using unit tests (xUnit / Vitest) and GitHub Actions.

- To automate deployment to production and reduce operational costs, I support CD using Docker and Render.

- To enable consistent development environments for myself or any future team members, I unified the development environment using Docker Compose.

Backend Architecture

This application organizes backend data retrieval and processing logic using the "Handler" pattern.

🔧 Tech Stack: ASP.NET Core, xUnit, NSwag

Details

Frontend Architecture

The frontend is structured using a combination of the "Container/Presentational pattern" and "state management with Hooks + Context". The main goal is to achieve separation of concerns, improving readability and scalability.

🔧 Tech Stack: React, TypeScript, Vite, Testing Library, Tailwind CSS, and more
